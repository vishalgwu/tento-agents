# Tento visual identity

Tento is a community-operations product. The identity pairs warm residential imagery with clear, credible software workflows.

## Visual vocabulary

- Forest: #1B342D. Primary actions, brand mark and dark editorial panels.
- Ivory: #F7F6F1. Main canvas and warm page backgrounds.
- Lime: #D5F477. Restrained highlights, brand doorway and key invitations.
- Sage and warm neutral borders support the palette; amber indicates records needing attention.
- Geist Sans supports navigation, forms and operations. Georgia supplies editorial display headings without an external font dependency. Existing Geist Mono remains available for technical identifiers.
- The wordmark, four-window symbol, favicon and workspace line icons are code-native SVG. The symbol includes a lime doorway detail.

## Imagery and content

The courtyard image in apps/web/public/images/tento-courtyard.png is an original AI-generated architectural brand image. It is conceptual imagery, not a photographed property listing or a customer project. Next.js Image supplies responsive image optimization and lazy loading; the homepage hero is prioritized.

Brindle's public multifamily design/branding guidance informed the emphasis on cohesive imagery, identity and journey. Its protected landing page was not copied. Reference: https://brindledigital.com/web-design/apartment/ .

No invented customers, endorsements, occupancy numbers or performance claims are presented. Workspace counters derive only from records already loaded for the authorized account. Capability limits remain visible in the product and release details.

## Interaction and access

Use one shared brand/header/footer system across the home page, login, resident flows and staff views. Preserve visible keyboard focus, associated labels, meaningful link names, accessible error messages and reduced-motion preferences. Responsive layouts cover compact phones, tablets and desktop. Decorated imagery never substitutes for a form label or permission check.

Roles, authentication, worker execution and tenant isolation are unchanged by this visual update. Core checks: production build/typecheck, existing HTTP proxy/role-flow suite, browser layout/overflow checks and live production smoke checks.
