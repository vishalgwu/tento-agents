# Shared UI

`@resident-os/ui` contains accessible visual primitives shared by the web application.

- `StatusLamp` displays urgency with both color and a written priority.
- `DecisionMarker` identifies an automated agent assessment.
- `EvidenceRail` and `EvidenceClaim` pair factual statements with source excerpts.

Components accept typed display data. They do not perform network requests or change workflow state.
